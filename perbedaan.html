Perbedaan Debian dan Centos

1. Arsitektur
dari arsitektur, Debian dan CentOS sangat populer untuk x86_64/AMD64. Tidak hanya itu, keduanya ikut mendukung Aarch64/ARM64 dan ppc64el/ppc64le. Debian juga mendukung armhr/armhfp dan i386. Untuk CentOS, hanya CentOS 7 yang mendukung kedua arsitektur tersebut. Ditambah, CentOS 7 juga mendukung POWER9, sementara CentOS 8 dan Debian tidak. Selain itu, Debian mendukung arsitektur MIPSel, MIPS64el dan s390x, sesuatu yang tidak CentOS miliki.

2. Package Management
Seperti yang terungkap sebelumnya, keduanya memiliki keunikan dalam aspek manajemen package. Memang sudah tidak mengherankan kebanyakan distribusi Linux memiliki package manager yang unik. Debian menggunakan package format DEB dan package manager dpkg/APT. Sedangkan CentOS (termasuk derivatif RHEL) menggunakan package format RPM dan package manager YUM/DNF. Package management kedua distribusi ini cukup kompleks. Setidaknya, terdapat dukungan repository berbasis jaringan dan package management berfitur penuh (full-feature).

3. Filesystem
Untuk filesystem, CentOS menggunakan XFS sebagai default. Debian cenderung menggunakan EXT4. Baik XFS dan EXT4 merupakan opsi populer untuk kedua distro ini. Di samping itu, Debian dan CentOS sama-sama mendukung filesystem GFS2, ext2/3, NFSv3/4, dan SMB. Meski begitu, CentOS tidak mendapat dukungan resmi beberapa filesystem yang ditawarkan Debian seperti ZFS.

4. Kernel
Debian memiliki 4.19 kernel, salah satu Linux kernel dengan dukungan hardware lebih teranyar dan tercanggih. Tentu ini menjadi keunggulan bagi siapapun yang ingin membangun server lebih canggih. CentOS sudah termasuk kernel 3.10 untuk CentOS 7 atau 4.18 untuk CentOS 8. Ada juga kernel-lt-5.4 dan kernel-ml-5.10 tetapi melalui pihak ketiga. Kedua distro server ini memiliki backport security. Hal tersebut akan meng-update kernel termasuk dari hal keamanan.

5. Upgrade
Debian selalu konsisten dalam menghadirkan major version. Tidak cuma itu, Sob, Debian juga memudahkan untuk meng-upgrade dari satu stable release menuju yang terbaru, menjadikan sistem tersebut bisa konsisten ter-update. Umumnya, Debian merilis major version terbaru setiap dua tahun dengan dukungan penuh sebanyak tiga tahun dan dua tahun tambahan untuk Long Term Support, menjadikan total lima tahun dukungan. Berbeda dari Debian, CentOS tidak mendukung upgrade major version seperti CentOS 6 menjadi CentOS 7. Sebaliknya, terdapat dukungan upgrade minor version seperti dari 7.8 ke 7.9. Setidaknya, setiap major version CentOS memiliki lifespan sebanyak 10 tahun secara resmi. Dengan begitu, ini menjadikannya cukup praktis jika ingin terpakai lebih lama.

6. Kemudahan Penggunaan
Debian cenderung mudah dan ramah pemula, termasuk UI dan GUI yang user-friendly. Sebaliknya, CentOS mungkin mudah untuk terinstal, tetapi UI dan GUI-nya justru sangat rumit. Kerumitan ini mungkin akan menyulitkan pengguna yang tidak ahli dalam aspek teknis.
